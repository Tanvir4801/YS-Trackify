=============================================================
WHAT I SAW (the real problem)
=============================================================

Supervisor scanned 4 labours at Site A (BITTU PANCHKAKDA).
Other 14 labours were accidentally marked Absent at Site A.
But those 14 actually work at Site B (KISHANBHAI KANGVAI).

Problem: Once marked Absent, they disappear from other sites.
If changed to Present, wage shows at wrong site.
There is NO way to say "this labour belongs to another site, 
I haven't decided yet" — there is no neutral/undecided state.

=============================================================
SOLUTION: ADD "PENDING" AS A 4TH STATUS
=============================================================

Add status: "pending" to attendance records.

Rules for PENDING status:
- Means: "not yet marked at any site today"
- Labour with PENDING status appears in ALL sites' labour list
- Labour with PENDING status does NOT count in Present/Absent/Half
- Labour with PENDING status does NOT add to wage calculation
- PENDING is the DEFAULT state (no attendance record = pending)
- Supervisor can set any marked labour BACK to Pending

This way:
- If accidentally marked Absent at Site A → set to Pending
- Labour now reappears in Site B, C, D list
- Supervisor marks them correctly at the right site
- No data is deleted — just status changes

## Change 1 — AttendanceStatus enum

Find lib/models/attendance_model.dart
Add pending to the enum:

```dart
enum AttendanceStatus {
  present,
  absent,
  half,
  pending, // ← ADD THIS
}

extension AttendanceStatusX on AttendanceStatus {
  String get firestoreValue {
    switch (this) {
      case AttendanceStatus.present: return 'present';
      case AttendanceStatus.absent:  return 'absent';
      case AttendanceStatus.half:    return 'half';
      case AttendanceStatus.pending: return 'pending';
    }
  }

  static AttendanceStatus fromFirestoreValue(String value) {
    switch (value) {
      case 'present': return AttendanceStatus.present;
      case 'absent':  return AttendanceStatus.absent;
      case 'half':    return AttendanceStatus.half;
      case 'pending': return AttendanceStatus.pending;
      default:        return AttendanceStatus.pending; // safe default
    }
  }

  // Factor for wage calculation
  // pending counts as 0 — not in wage total
  double get factor {
    switch (this) {
      case AttendanceStatus.present: return 1.0;
      case AttendanceStatus.half:    return 0.5;
      case AttendanceStatus.absent:  return 0.0;
      case AttendanceStatus.pending: return 0.0; // excluded from wages
    }
  }

  bool get isMarked =>
    this == AttendanceStatus.present ||
    this == AttendanceStatus.absent  ||
    this == AttendanceStatus.half;
    // pending is NOT considered "marked"
}
```

## Change 3 — AttendanceService: mark as pending

```dart
// In lib/services/attendance_service.dart

Future<void> markAsPending(String labourId, String date) async {
  final uid = _requireUid();

  // Find existing attendance record for this labour today
  final existing = await _db
      .collection('attendance')
      .where('labourId',     isEqualTo: labourId)
      .where('supervisorId', isEqualTo: uid)
      .where('date',         isEqualTo: date)
      .get();

  if (existing.docs.isEmpty) {
    // No record — already effectively pending, nothing to do
    debugPrint('markAsPending: no record found for $labourId on $date');
    return;
  }

  // Update ALL records for this labour today to pending
  // (in case there are multiple from different sites)
  final batch = _db.batch();
  for (var doc in existing.docs) {
    batch.update(doc.reference, {
      'status':    'pending',
      'updatedAt': FieldValue.serverTimestamp(),
      'pendingAt': FieldValue.serverTimestamp(),
      'pendingReason': 'reset_by_supervisor',
    });
  }
  await batch.commit();

  // Update Hive
  final hiveKey = '${labourId}_$date';
  final box = _attendanceBox;
  final local = box.get(hiveKey);
  if (local != null) {
    local.status = AttendanceStatus.pending;
    local.isSynced = true;
    await box.put(hiveKey, local);
  }

  debugPrint('markAsPending: $labourId set to pending on $date');
}
```

```dart
Future<void> markAttendance(String labourId, String status) async {
  // Optimistic update
  if (status == 'pending') {
    attendanceMap.remove(labourId);
    allTodayMap.remove(labourId); // makes them available in other sites
  } else {
    attendanceMap[labourId] = status;
    if (AttendanceStatusX.fromFirestoreValue(status).isMarked) {
      allTodayMap[labourId] =
          AttendanceStatusX.fromFirestoreValue(status);
    }
  }
  notifyListeners();

  // Call service
  if (status == 'pending') {

      id:           '${labourId}_$selectedDateStr',
      labourId:     labourId,

      date:         selectedDateStr,
      status:       AttendanceStatusX.fromFirestoreValue(status),
      overtimeHours: overtimeMap[labourId] ?? 0,

  }
```

## Change 12 — Contractor sees ONLY their own data

Create src/hooks/useContractorFilter.js:
```javascript
import { useAuth } from '../context/AuthContext';

export function useContractorFilter() {
  const { userProfile } = useAuth();

  // Admin sees all — no filter
  // Contractor sees only their own data
  const contractorId = userProfile?.isContractor
    ? userProfile.contractorId || userProfile.uid
    : null; // null = no filter = admin sees all

  // Build Firestore constraint
  const getConstraint = (field = 'supervisorId') =>
    contractorId ? where(field, '==', contractorId) : null;

  return { contractorId, getConstraint, isContractor: userProfile?.isContractor };
}
```

Use in every data hook:

```jsx
    if (!contractorId) return;

    // Live sites
    const siteSub = onSnapshot(
      query(collection(db, 'sites'),
        where('contractorId', '==', contractorId),
        where('isActive', '==', true)),
      snap => setSites(snap.docs.map(d => ({ id: d.id, ...d.data() })))
    );

    // Live today attendance summary per site
    const attSub = onSnapshot(
      query(collection(db, 'attendance'),
        where('supervisorId', '==', contractorId),
        where('date', '==', today)),
      snap => {
        const bysite = {};
        snap.docs.forEach(d => {
          const siteId = d.data().siteId || 'no_site';
          if (!bysite[siteId]) {
            bysite[siteId] = { present: 0, absent: 0, half: 0,
                               pending: 0, wage: 0 };
          }
          const status = d.data().status;
          const wage   = d.data().dailyWageSnapshot || 0;
          if (status === 'present') {
            bysite[siteId].present++;
            bysite[siteId].wage += wage;
          } else if (status === 'absent') {
            bysite[siteId].absent++;
          } else if (status === 'half') {
            bysite[siteId].half++;
            bysite[siteId].wage += wage / 2;
          } else {
            bysite[siteId].pending++;
          }
        });
        setSummary(bysite);
      }
    );

    return () => { siteSub(); attSub(); };
  }, [contractorId, today]);

  return (
    <div className="p-6">
      <h2 className="text-xl font-bold mb-4">
        Today's Sites — {new Date().toLocaleDateString('en-IN',
          { weekday:'long', day:'numeric', month:'long' })}
      </h2>
      <div className="grid gap-4">
        {sites.map(site => {
          const s = summary[site.id] || {};
          return (
            <div key={site.id}
              className="bg-white border rounded-xl p-4 shadow-sm">
              <div className="flex justify-between items-start">
                <div>
                  <h3 className="font-bold text-lg">{site.name}</h3>
                  <p className="text-gray-500 text-sm">{site.location}</p>
                </div>
                <span className={`px-3 py-1 rounded-full text-xs font-bold
                  ${(s.pending || 0) === 0
                    ? 'bg-green-100 text-green-700'
                    : 'bg-amber-100 text-amber-700'}`}>
                  {(s.pending || 0) === 0 ? '✓ COMPLETE' : 'PENDING'}
                </span>
              </div>
              <div className="flex gap-4 mt-3 text-sm">
                <span className="text-green-600">
                  ✓ {s.present || 0} Present
                </span>
                <span className="text-red-500">
                  ✗ {s.absent || 0} Absent
                </span>
                <span className="text-amber-500">
                  ½ {s.half || 0} Half
                </span>
                <span className="text-gray-400">
                  ⏳ {s.pending || 0} Pending
                </span>
              </div>
              <div className="mt-2 pt-2 border-t">
                <span className="text-sm font-semibold">
                  Today Wage: ₹{(s.wage || 0).toLocaleString('en-IN')}
                </span>
              </div>
            </div>
          );
        })}
      </div>
    </div>
  );
}
```
